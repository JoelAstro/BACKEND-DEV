## Development Standards and Guidelines

The following practices are maintained throughout this repository:

- **Organized Structure:** Each laboratory has its own dedicated folder.
- **Individual Documentation:** Every completed lab contains a separate README.md.
- **Clean Git Tracking:** `node_modules/` and unnecessary files are excluded using `.gitignore`.
- **Security:** Environment variables and sensitive credentials are never committed.
- **Reproducibility:** Installation instructions and execution commands are documented.
- **API Testing:** Endpoints are tested using Postman wherever applicable.
- **Database Verification:** Database operations are verified using appropriate database tools.
- **Screenshots:** Working outputs and important implementation results are documented.
- **Meaningful Commits:** Git commits use clear descriptions of completed work.
